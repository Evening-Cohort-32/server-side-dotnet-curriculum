# Book 5 - Server-Side Rendering with ASP.NET MVC
So far in the course, the HTML that appears in your browser has mostly been generated by JavaScript _in your browser_, as part of your React applications. In this book you will get an introduction to _server-side rendered_ web applications, where the server builds the HTML for each page and sends it to the browser ready to display. You'll learn the MVC (Model, View, Controller) pattern by building DeShawn's Dog Walking one more time, so that all of your attention can go to _how_ the app is built, instead of _what_ it does. There is no coding assessment for this book.

## Learning Objectives
1. Server-side rendering vs. client-side rendering
1. The MVC pattern
    - Conventional routing
    - Controllers and actions that return views
    - Razor views and layouts
1. Forms
    - Tag helpers
    - Model binding
    - Anti-forgery tokens
1. View models
1. Server-side and client-side validation
