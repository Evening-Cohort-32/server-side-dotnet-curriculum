# Practice: Conditionals & Loops

Short, standalone drills for control flow syntax. Each one only needs a `Program.cs` you can throw away when you're done - no project setup required. Pick whichever ones match what you're rusty on; you don't need to do them in order.

← Back to [Conditionals & Loops](./resource-02-conditionals-and-loops.md)

1. Given an `int score`, write an `if`/`else if`/`else` chain that prints "Pass" for 60 or above and "Fail" otherwise. Try it with a couple different scores.

1. Given `int day = 4;`, write a `switch` statement that prints the day name for values 1-7 and "Invalid day" for anything else.

1. Rewrite question 1's pass/fail check as a one-line ternary expression instead.

1. Use a `for` loop to print every multiple of 3 between 1 and 30.

1. Use a `while` loop to print numbers counting down from 10 to 1. Then write a second loop over the same range that uses `continue` to skip printing 5, and `break` to stop entirely once it reaches 2.
