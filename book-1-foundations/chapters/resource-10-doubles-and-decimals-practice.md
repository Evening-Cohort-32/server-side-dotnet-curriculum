# Practice: Doubles & Decimals

Short, standalone drills for `double` and `decimal` syntax. Each one only needs a `Program.cs` you can throw away when you're done - no project setup required. Pick whichever ones match what you're rusty on; you don't need to do them in order.

← Back to [Doubles & Decimals](./resource-10-doubles-and-decimals.md)

1. Declare `decimal price = 19.99;` without the `M` suffix and see what the compiler says. Fix it by adding `M`.

1. Declare `double a = 0.1 + 0.2;` and `decimal b = 0.1M + 0.2M;`, print both, and compare the results.

1. Given `List<decimal> prices = new List<decimal> { 12.50M, 8.75M, 3.20M };`, use a `foreach` loop to accumulate and print the total.

1. Given `decimal itemPrice = 24.99M;` and `int quantity = 3;`, calculate and print the total cost.

1. For each of the following, declare a variable with a plausible value using the type you think fits best (`int`, `double`, or `decimal`), and add a comment explaining your choice: a person's age, an item's price, a rocket's fuel-burn rate in liters per second.
