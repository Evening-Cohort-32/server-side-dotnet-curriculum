# Practice: Methods

Short, standalone drills for defining and calling methods. Each one only needs a `Program.cs` you can throw away when you're done - no project setup required. Pick whichever ones match what you're rusty on; you don't need to do them in order.

← Back to [Methods](./resource-11-foundations-methods.md)

1. Write a `void` method called `PrintGreeting` that takes no parameters and prints a greeting. Call it.

1. Add a `string name` parameter to `PrintGreeting` so it prints a personalized greeting. Call it with a couple different names.

1. Write a method `Add(int a, int b)` that returns their sum as an `int`. Call it and print the result.

1. Write a method `IsEven(int number)` that returns a `bool` indicating whether the number is even. Test it with a few different inputs, including 0 and a negative number.

1. Write a method `AverageOf(List<int> numbers)` that returns a `double` - the average of the list. Test it with a list of your choosing.
