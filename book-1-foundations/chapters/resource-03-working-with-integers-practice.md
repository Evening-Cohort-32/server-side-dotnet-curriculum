# Practice: Numbers

Short, standalone drills for numeric types and operations. Each one only needs a `Program.cs` you can throw away when you're done - no project setup required. Pick whichever ones match what you're rusty on; you don't need to do them in order.

← Back to [Numbers](./resource-03-working-with-integers.md)

1. Given `int a = 17; int b = 5;`, print the result of `+`, `-`, `*`, `/`, and `%`. Then cast one operand to `double` and print the division again - compare the two results.

1. Starting from `int x = 10;`, apply `+=`, `-=`, `*=`, and `/=` one after another, printing `x` after each step so you can see it change.

1. Given `int i = 5;`, write one line using `i++` (postfix) and one using `++i` (prefix), each assigned to a different variable. Print both the original and the new variable to see the difference.

1. Using the `Math` class, print `Math.Sqrt()` of 144, `Math.Pow()` of 2 raised to 10, and `Math.Round()`, `Math.Ceiling()`, and `Math.Floor()` all applied to `7.5`.

1. Given `double price = 49.999;`, print it formatted as currency (`:C`) and to 2 decimal places (`:F2`). Then cast it `(int)` and print that too - notice it truncates rather than rounds.
